---

> **Designer Instructions:** This is a single-page (8.5x11 or A4) high-impact flyer for emailing to prospects and printing for in-person visits. Use brand colors. Make it scannable — a prospect should get the key message in 5 seconds.

## DESIGN SPECIFICATIONS

| Element | Specification |
|---------|--------------|
| Page size | 8.5" x 11" |
| Orientation | Portrait |
| Background | White with brand color accents |
| Primary font | Montserrat Bold (headings) |
| Body font | Open Sans or Arial 10pt |
| Icon style | Flat icons from Flaticon or Noun Project (food/packaging category) |
| Export | PDF (print) + JPG or PNG (email/web) |
| File size target | < 2MB for email version |
